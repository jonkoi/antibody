# abguard --help
                                                                                
 Usage: abguard [OPTIONS] COMMAND [ARGS]...                                     
                                                                                
 Liability and novelty checks for antibody design submissions.                  
                                                                                
 Validates VHH, scFv and paired-antibody design tables against a dataframely    
 schema (IMGT-numberable, valid amino acids, <=250 residues per chain, no       
 unpaired cysteines, unique IDs) and reports sequence liabilities from the LAP  
 Antibody Liability Reference (PLOS Comput Biol 2024;20(3):e1011881).           
                                                                                
 With --reference-db it also applies the novelty gate: a design must differ     
 from trastuzumab and from every known CDRH3 by at least 3 mutations in CDRH3   
 if it is a trastuzumab variant (>=70% identity), or 2 if it is de novo.

│ --help          Show this message and exit.                                  │
╰──────────────────────────────────────────────────────────────────────────────╯
╭─ Commands ───────────────────────────────────────────────────────────────────╮
│ team-validate         Validate one team's submission table.                  │
│ competition-validate  Validate every team's submission in a folder and       │
│                       reject shared sequences.                               │

│ reference-export      Package a reference database as a Parquet bundle, for  │
│                       shipping.                                              │
│ reference-info        List the tables in a reference and which column each   │
│                       is numbered on.                                        │

│                       implements.                                            │
│ dashboard             Launch the marimo liability dashboard.                 │
